# Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website built with vanilla HTML5, CSS3, and JavaScript. Designed to showcase developer projects, technical skills, and professional contact information.

## 🚀 Features
- **Semantic HTML5 Structure:** Built using proper layout tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) for better accessibility and SEO.
- **Fully Responsive:** Optimized for various screen sizes including mobile (375px), tablets (768px), and desktops (1280px+).
- **Interactive Mobile Menu:** JavaScript-powered hamburger navigation toggle for seamless mobile browsing.
- **Featured Projects Grid:** Dedicated showcase area highlighting projects with descriptions, tech stacks, and direct links.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Media Queries)
- **JavaScript (ES6+)**
